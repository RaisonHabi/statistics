在电商 A/B 实验中，GMV（商品交易总额）属于连续型变量（Continuous Metric），通常使用 双样本 Z 检验（Z-Test） 或 T 检验（T-Test） 来衡量实验组与对照组之间的差异显著性。由于电商实验通常样本量巨大，两者计算结果趋于一致，常统一使用 Z 检验。  
以下是具体的计算步骤与公式：
### 1. 计算 Z 值 (Z-score) 
Z 值代表实验组均值与对照组均值之间的标准化距离。  
公式：  
Z = (X_B-X_A)/sqrt(S_A^2/n_A + S_B^2/n_B)   
* X_A,X_B：对照组 A 和实验组 B 的人均 GMV（总 GMV / 用户数）。
* S_A^2,S_B^2：对照组 A 和实验组 B 的样本方差。
* * 注：计算方差时需考虑所有用户，包括 GMV 为 0 的未购买用户。
* n_A,n_B：各组的样本量（用户数）。
### 2. 计算 P 值 (P-value)
P 值表示在“实验无效果（原假设为真）”的情况下，观察到当前差异或更大差异的概率。   
* 计算方法： 获取 Z 值后，通过查询 标准正态分布表 或使用编程工具（如 Python 的 scipy.stats.norm.sf）计算双尾概率。
* Python 代码示例：
  ```
  from scipy.stats import norm
  # 假设计算出的 Z 值为 2.23
  p_value = 2 * (1 - norm.cdf(abs(Z)))
  ```
请谨慎使用此类代码。

### 4. 进阶建议：Delta Method
在电商 GMV 实验中，有时关注的是 人均客单价 (GMV/购买人数) 这种比率指标。由于分母（购买人数）也是随机变量，传统的 Z 检验公式会失效。此时需要使用 Delta Method (德尔塔法) 来重新估计方差，以获得准确的 Z 值和 P 值。
