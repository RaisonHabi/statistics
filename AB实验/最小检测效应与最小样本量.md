<h2 id="h_15833114070_1" data-into-catalog-status="">一、最小检测效应</h2><p data-pid="yTGtcd0L">在假设检验中，<b>最小可检测效应（Minimum Detectable Effect, MDE）</b> 是指在给定样本量、<span data-search-entity="2">显著性水平</span>（ <span class="ztext-math" data-eeimg="1" data-tex="\alpha">\alpha</span> ）和<span data-search-entity="0">统计功效</span>（ <span class="ztext-math" data-eeimg="1" data-tex="1-\beta">1-\beta</span> ）的条件下，检验能够显著检测到的最小效应大小。推导过程如下：</p><h3 id="h_15833114070_2" data-into-catalog-status=""><b>1、问题设定</b></h3><p data-pid="3Wglz4A3">以双样本均值差检验为例：</p><ul><li data-pid="QP1YxSYD">原假设： <span class="ztext-math" data-eeimg="1" data-tex="H_0: \mu_1 = \mu_2">H_0: \mu_1 = \mu_2</span> </li><li data-pid="vzr_BPFJ">备择假设： <span class="ztext-math" data-eeimg="1" data-tex="H_1: \mu_1 \neq \mu_2">H_1: \mu_1 \neq \mu_2</span> </li><li data-pid="9TGreijA">显著性水平： <span class="ztext-math" data-eeimg="1" data-tex="\alpha">\alpha</span> </li><li data-pid="NE5MFhdF">统计功效： <span class="ztext-math" data-eeimg="1" data-tex="1-\beta">1-\beta</span> </li><li data-pid="dE2VZKJY">样本量：单组样本量为 <span class="ztext-math" data-eeimg="1" data-tex="n">n</span> ，总样本量为 <span class="ztext-math" data-eeimg="1" data-tex="2n">2n</span> </li><li data-pid="d1BGowQX">效应大小： <span class="ztext-math" data-eeimg="1" data-tex="\Delta = \mu_2 - \mu_1">\Delta = \mu_2 - \mu_1</span> ，不妨设 <span class="ztext-math" data-eeimg="1" data-tex="\Delta &gt;0">\Delta &gt;0</span> </li><li data-pid="B6_6Uate">总体标准差： <span class="ztext-math" data-eeimg="1" data-tex="\sigma">\sigma</span> </li></ul><p data-pid="8lxNgW-B">我们的目标，是推导出，在给定样本量，显著性水平，统计功效的前提下，能够被检验检测的最小效应大小 <span class="ztext-math" data-eeimg="1" data-tex="\Delta_{\text{min}}">\Delta_{\text{min}}</span></p><h3 id="h_15833114070_3" data-into-catalog-status="">2、<b>检验统计量</b></h3><p data-pid="f3a03-Z-">假设数据服从<span data-search-entity="1">正态分布</span>，总体方差已知。检验统计量为：</p><p data-pid="LTWmJ4Xp"><span class="ztext-math" data-eeimg="1" data-tex="Z = \frac{\bar{X}_2 - \bar{X}_1 - (\mu_2 - \mu_1)}{\sqrt{\frac{\sigma^2}{n} + \frac{\sigma^2}{n}}}">Z = \frac{\bar{X}_2 - \bar{X}_1 - (\mu_2 - \mu_1)}{\sqrt{\frac{\sigma^2}{n} + \frac{\sigma^2}{n}}}</span> <br/>化简为：</p><p data-pid="hCI-SGBa"><span class="ztext-math" data-eeimg="1" data-tex="Z = \frac{\bar{X}_2 - \bar{X}_1 - (\mu_2 - \mu_1)}{\sqrt{\frac{2\sigma^2}{n}}}">Z = \frac{\bar{X}_2 - \bar{X}_1 - (\mu_2 - \mu_1)}{\sqrt{\frac{2\sigma^2}{n}}}</span> <br/>在原假设成立 ( <span class="ztext-math" data-eeimg="1" data-tex="H_0: \mu_1 = \mu_2">H_0: \mu_1 = \mu_2</span> ) 下：</p><p data-pid="lpq3P7KI"><span class="ztext-math" data-eeimg="1" data-tex="Z \sim N(0, 1)">Z \sim N(0, 1)</span> </p><p data-pid="QZvm1bAR">在备择假设成立 ( <span class="ztext-math" data-eeimg="1" data-tex="H_1: \mu_1 \neq \mu_2">H_1: \mu_1 \neq \mu_2</span> ) 下：</p><p data-pid="ClbuLxdB"><span class="ztext-math" data-eeimg="1" data-tex="Z \sim N\left(\frac{\Delta}{\sqrt{\frac{2\sigma^2}{n}}}, 1\right) ">Z \sim N\left(\frac{\Delta}{\sqrt{\frac{2\sigma^2}{n}}}, 1\right) </span> </p><h3 id="h_15833114070_4" data-into-catalog-status=""><b>3、显著性水平的拒绝域</b></h3><p data-pid="zHZSp1ON">显著性水平 <span class="ztext-math" data-eeimg="1" data-tex="\alpha">\alpha</span> 定义了双侧检验的拒绝域： <span class="ztext-math" data-eeimg="1" data-tex="|Z| &gt; z_{\alpha/2}">|Z| &gt; z_{\alpha/2}</span> </p><p data-pid="QCtCcwk5">其中， <span class="ztext-math" data-eeimg="1" data-tex="z_{\alpha/2}">z_{\alpha/2}</span> 是标准正态分布下，使两尾累计概率为 <span class="ztext-math" data-eeimg="1" data-tex="\alpha">\alpha</span> 的分位数。</p><h3 id="h_15833114070_5" data-into-catalog-status="">4、<b>统计功效的条件</b></h3><p data-pid="K4c1c00g">统计功效 <span class="ztext-math" data-eeimg="1" data-tex="1-\beta ">1-\beta </span> ，是在备择假设成立时正确拒绝原假设的概率：</p><p data-pid="pql_jTeY"><span class="ztext-math" data-eeimg="1" data-tex="P(\text{拒绝 } H_0 \mid H_1) = P(Z &lt; -z_{\alpha/2} \mid H_1) + P(Z &gt; z_{\alpha/2} \mid H_1)">P(\text{拒绝 } H_0 \mid H_1) = P(Z &lt; -z_{\alpha/2} \mid H_1) + P(Z &gt; z_{\alpha/2} \mid H_1)</span> </p><p data-pid="gavV1t0p">在 <span class="ztext-math" data-eeimg="1" data-tex="H_1">H_1</span> 成立时，统计量 Z 服从正态分布，其分布均值为 <span class="ztext-math" data-eeimg="1" data-tex="\frac{\Delta}{\sqrt{\frac{2\sigma^2}{n}}}">\frac{\Delta}{\sqrt{\frac{2\sigma^2}{n}}}</span> ，标准差为 1</p><p data-pid="bRd7xobs">其中，在 <span class="ztext-math" data-eeimg="1" data-tex="\Delta &gt;0">\Delta &gt;0</span> 时，备择假设 <span class="ztext-math" data-eeimg="1" data-tex="H_1">H_1</span> 成立下 <span class="ztext-math" data-eeimg="1" data-tex="Z">Z</span> 正态分布函数，在原假设 <span class="ztext-math" data-eeimg="1" data-tex="H_0">H_0</span> 成立下 <span class="ztext-math" data-eeimg="1" data-tex="Z">Z</span> 的正态分布函数的右侧，所以 <span class="ztext-math" data-eeimg="1" data-tex="P(Z &lt; -z_{\alpha/2} \mid H_1)">P(Z &lt; -z_{\alpha/2} \mid H_1)</span> 的值很小，我们忽略不计，我们只计算 <span class="ztext-math" data-eeimg="1" data-tex="P(Z &gt; z_{\alpha/2} \mid H_1)">P(Z &gt; z_{\alpha/2} \mid H_1)</span> </p><p data-pid="ECyH7r0n">则当 <span class="ztext-math" data-eeimg="1" data-tex="Z \sim N\left(\frac{\Delta}{\sqrt{\frac{2\sigma^2}{n}}}, 1\right)">Z \sim N\left(\frac{\Delta}{\sqrt{\frac{2\sigma^2}{n}}}, 1\right)</span> 时， <span class="ztext-math" data-eeimg="1" data-tex="P(Z &gt; z_{\alpha/2} \mid H_1)  ">P(Z &gt; z_{\alpha/2} \mid H_1)  </span> 可以写为： <span class="ztext-math" data-eeimg="1" data-tex="P(\text{拒绝 } H_0 \mid H_1) = 0+P(Z &gt; z_{\alpha/2} \mid H_1) = 1-P\left( Z &lt; z_{\alpha/2} -\frac{\Delta}{\sqrt{\frac{2\sigma^2}{n}}}  \right)">P(\text{拒绝 } H_0 \mid H_1) = 0+P(Z &gt; z_{\alpha/2} \mid H_1) = 1-P\left( Z &lt; z_{\alpha/2} -\frac{\Delta}{\sqrt{\frac{2\sigma^2}{n}}}  \right)</span> </p><p data-pid="Jr1fLune">根据统计功效定义，解得：</p><p data-pid="Hup9XIP5"><span class="ztext-math" data-eeimg="1" data-tex="\frac{\Delta}{\sqrt{\frac{2\sigma^2}{n}}} - z_{\alpha/2} = z_\beta">\frac{\Delta}{\sqrt{\frac{2\sigma^2}{n}}} - z_{\alpha/2} = z_\beta</span> ，其中， <span class="ztext-math" data-eeimg="1" data-tex="z_\beta">z_\beta</span> 是标准正态分布下的 <span class="ztext-math" data-eeimg="1" data-tex="\beta">\beta</span> 分位数。</p><h3 id="h_15833114070_6" data-into-catalog-status=""><b>5、最小效应大小的推导</b></h3><p data-pid="jfi-1Yqz">将统计功效条件公式整理为效应大小 <span class="ztext-math" data-eeimg="1" data-tex="\Delta ">\Delta </span> 的表达式：</p><p data-pid="c61pS5oT"><span class="ztext-math" data-eeimg="1" data-tex="\frac{\Delta}{\sqrt{\frac{2\sigma^2}{n}}} = z_{\alpha/2} + z_\beta">\frac{\Delta}{\sqrt{\frac{2\sigma^2}{n}}} = z_{\alpha/2} + z_\beta</span> </p><p data-pid="A7AAhHeo">解出  <span class="ztext-math" data-eeimg="1" data-tex="\Delta = \sqrt{\frac{2\sigma^2}{n}} \cdot (z_{\alpha/2} + z_\beta)">\Delta = \sqrt{\frac{2\sigma^2}{n}} \cdot (z_{\alpha/2} + z_\beta)</span> </p><p data-pid="zFgEwUcT">将其定义为最小可检测效应 <span class="ztext-math" data-eeimg="1" data-tex="\Delta_{\text{min}}">\Delta_{\text{min}}</span> ：</p><p data-pid="1rxmcLgD"><span class="ztext-math" data-eeimg="1" data-tex="\Delta_{\text{min}} = \sqrt{\frac{2\sigma^2}{n}} \cdot (z_{\alpha/2} + z_\beta)">\Delta_{\text{min}} = \sqrt{\frac{2\sigma^2}{n}} \cdot (z_{\alpha/2} + z_\beta)</span> </p><h3 id="h_15833114070_7" data-into-catalog-status=""><b>6、最终公式</b></h3><p data-pid="woaxsAc7">最小可检测效应大小为：</p><p data-pid="LalX39f6"><span class="ztext-math" data-eeimg="1" data-tex="\Delta_{\text{min}} = \sqrt{\frac{2\sigma^2}{n}} \cdot (z_{\alpha/2} + z_\beta)">\Delta_{\text{min}} = \sqrt{\frac{2\sigma^2}{n}} \cdot (z_{\alpha/2} + z_\beta)</span> </p><ul><li data-pid="wrJZro22"><span class="ztext-math" data-eeimg="1" data-tex="z_{\alpha/2}">z_{\alpha/2}</span> ：显著性水平对应的正态分布分位数。如果单边研究则是 <span class="ztext-math" data-eeimg="1" data-tex="z_{\alpha}">z_{\alpha}</span> </li><li data-pid="DnrdXZ3Y"><span class="ztext-math" data-eeimg="1" data-tex="z_\beta">z_\beta</span> ：统计功效对应的正态分布分位数。</li><li data-pid="cIUVEZPy"><span class="ztext-math" data-eeimg="1" data-tex="\sigma^2">\sigma^2</span> ：总体方差。</li><li data-pid="ysLB03Fl"><span class="ztext-math" data-eeimg="1" data-tex="n">n</span> ：单组样本量。</li></ul><h3 id="h_15833114070_8" data-into-catalog-status=""><br/>7、<b>总结</b></h3><ul><li data-pid="z_fFVVW-"><b>公式</b>：最小可检测效应大小由显著性水平、统计功效、样本量和样本标准差决定。</li><li data-pid="1JED6yMl"><b>特性</b>： </li><ul><li data-pid="Q9spwuHn">当样本量增加时， <span class="ztext-math" data-eeimg="1" data-tex="\Delta_{\text{min}}">\Delta_{\text{min}}</span> 减小，表示实验更敏感。</li><li data-pid="peJ2Z3Ls">当显著性水平或统计功效要求更高时， <span class="ztext-math" data-eeimg="1" data-tex="\Delta_{\text{min}} ">\Delta_{\text{min}} </span> 增大，表示需要更大效应才能被检测。</li></ul><li data-pid="WyRYqzNc"><b>意义</b>：MDE 帮助研究者评估实验设计的能力，以确保合理的样本量分配和资源优化。</li></ul><h2 id="h_15833114070_9" data-into-catalog-status=""><br/>二、最小样本量</h2><p data-pid="I4FDa9MA">根据，最小可检测效应大小公式为：</p><p data-pid="BBFhk0Up"><span class="ztext-math" data-eeimg="1" data-tex="\Delta_{\text{min}} = \sqrt{\frac{2\sigma^2}{n}} \cdot (z_{\alpha/2} + z_\beta)">\Delta_{\text{min}} = \sqrt{\frac{2\sigma^2}{n}} \cdot (z_{\alpha/2} + z_\beta)</span> </p><p data-pid="90R0Z3_U">如果，我们提前给定我们希望检测到的最小预期效应 <span class="ztext-math" data-eeimg="1" data-tex="\Delta">\Delta</span> ，则上述公式可变为</p><p data-pid="mTUPQ8yG"><span class="ztext-math" data-eeimg="1" data-tex="n = \frac{2\sigma^2}{\Delta_{\text{min}}^2} \cdot (z_{\alpha/2} + z_\beta)^2">n = \frac{2\sigma^2}{\Delta_{\text{min}}^2} \cdot (z_{\alpha/2} + z_\beta)^2</span> </p><h2 id="h_15833114070_10" data-into-catalog-status="">三、<b>案例</b></h2><p data-pid="23VQRsed">目前，某电商平台某产品的GMV销售额为每日人均 2 万元，希望通过修改按钮样式，以提升每日人均 GMV交易额。</p><p data-pid="28wnzwNe">为了检测这个产品能力优化，其修改按钮是否能够带来每日人均 GMV 交易额的提升，我们进行AB实验，我们设置实现显著性水平为5%，统计功效80%，AB两组各的样本量分别为1000个样本，原该产品的GMV交易额的样本方差为2000元。</p><p data-pid="wx2sxuFi">最小检测效应公式为</p><p data-pid="ohUEM5mC"><span class="ztext-math" data-eeimg="1" data-tex="\Delta_{\text{min}} = \sqrt{\frac{2\sigma^2}{n}} \cdot (z_{\alpha} + z_\beta)">\Delta_{\text{min}} = \sqrt{\frac{2\sigma^2}{n}} \cdot (z_{\alpha} + z_\beta)</span> <br/>其中， <span class="ztext-math" data-eeimg="1" data-tex="n=10000">n=10000</span> ， <span class="ztext-math" data-eeimg="1" data-tex="\sigma=2000">\sigma=2000</span> ， <span class="ztext-math" data-eeimg="1" data-tex="z_{\alpha}=1.645">z_{\alpha}=1.645</span> ， <span class="ztext-math" data-eeimg="1" data-tex="z_{\beta}=0.84">z_{\beta}=0.84</span> ，</p><p data-pid="ebS_2GqE">带入上式得<br/> <span class="ztext-math" data-eeimg="1" data-tex="\Delta_{\text{min}} = \sqrt{\frac{2\times2000^2}{1000}} \cdot (1.645 + 0.84)=222.2">\Delta_{\text{min}} = \sqrt{\frac{2\times2000^2}{1000}} \cdot (1.645 + 0.84)=222.2</span> </p><p data-pid="CsadAFkm">意味着，这个实验设置的前提，为了能够保证不犯一类错误和二类错误，这个修改按钮的产品优化，需要至少提升每日人均GMV交易额要222.2以上，我们才能有效的检测来。</p><p data-pid="Z6pqk6__">如果，我们的对这项优化，每日GMV交易额的最小预期提升为100元，即我们希望通过这个策略的调整，能够从每日人均2万一交易额，提升到2.01万交易额，在显著性水平为5%，统计功效80%的情况下，我们需要多少实验样本，才能检测出来？</p><p data-pid="nSX9lQ0f"><span class="ztext-math" data-eeimg="1" data-tex="n = \frac{2\sigma^2}{\Delta_{\text{min}}^2} \cdot (z_{\alpha} + z_\beta)^2">n = \frac{2\sigma^2}{\Delta_{\text{min}}^2} \cdot (z_{\alpha} + z_\beta)^2</span> </p><p data-pid="ZUDPfQIT">其中， <span class="ztext-math" data-eeimg="1" data-tex="\sigma=2000">\sigma=2000</span> ， <span class="ztext-math" data-eeimg="1" data-tex="\Delta_{min}=100">\Delta_{min}=100</span> ， <span class="ztext-math" data-eeimg="1" data-tex="z_{\alpha}=1.645">z_{\alpha}=1.645</span> ， <span class="ztext-math" data-eeimg="1" data-tex="z_{\beta}=0.84">z_{\beta}=0.84</span> ，带入上式得</p><p data-pid="AtVA0I0W"><span class="ztext-math" data-eeimg="1" data-tex="n = \frac{2\times 2000^2}{100^2} \cdot (1.645 + 0.84)^2=4940.18">n = \frac{2\times 2000^2}{100^2} \cdot (1.645 + 0.84)^2=4940.18</span> </p><p data-pid="KQ3ehEfI">即我们AB实验每组需要准备4941个样本，才能将最小预期提升为100元的变动，在设定的显著性水平和统计功效前提下，检测出来。</p></div>
